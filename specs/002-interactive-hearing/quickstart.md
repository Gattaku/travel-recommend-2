# Quickstart: インタラクティブ・ヒアリング機能

## 前提条件

- travel-recommend プロジェクトがセットアップ済み
- Supabase プロジェクトが稼働中
- 002_hearing_profiles.sql マイグレーション適用済み

## シナリオ 1: ヒアリングを通じた提案（P1 MVP）

1. ログイン後、提案ページにアクセス
2. 基本条件を入力（大人2名、子供1名(5歳)、夏、国内、予算10万、自然体験）
3. 「もっと詳しく教える」ボタンをクリック
4. ヒアリング質問に回答:
   - 家族の趣味: 釣り、写真撮影
   - 旅行で重視すること: 景色、食事
   - 子供が喜ぶ体験: 虫取り、川遊び
   - 移動手段: 車
   - 食事のこだわり: 地元料理
5. 「この条件で提案して」をクリック
6. 回答内容を反映した提案が表示されることを確認
   - 川遊びスポットや昆虫採集ができる場所を含む提案が出る

## シナリオ 2: ヒアリングスキップ（既存フロー維持）

1. 基本条件を入力
2. 「旅行先を提案して」をクリック（ヒアリングをスキップ）
3. 従来通りの基本条件のみの提案が表示されることを確認

## シナリオ 3: 提案後の再ヒアリング

1. 基本条件のみで提案結果を表示
2. 「もっと絞り込む」ボタンをクリック
3. ヒアリング画面が表示される
4. 追加情報を入力して「この条件で提案して」をクリック
5. 絞り込まれた提案が表示されることを確認

## シナリオ 4: プロフィール保存と再利用（P2）

1. シナリオ 1 を完了
2. 新しい提案リクエストを開始
3. 「もっと詳しく教える」をクリック
4. 前回の回答がプリセットされていることを確認
5. 一部を変更して再提案

## シナリオ 5: 動的質問（P3）

1. 家族構成に「1歳」を含めて入力
2. 「もっと詳しく教える」をクリック
3. 幼児向け質問（ベビーカー対応、離乳食）が表示されることを確認
4. エリアを「海外」に変更
5. 海外向け質問（言語、フライト時間）が表示されることを確認
